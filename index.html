I. 执行纪律 / 前提 / 仓位约束

通用执行原则（数据恢复后仍然适用）

  • 可立即执行的指令：减仓、清仓、止损、回补空头期权、不破坏持仓结构的小幅调整。这类动作只需满足触发条件即可执行。
  • 需人工确认的指令：任何开新仓、任何新增期权策略（covered call / protective put / collar / 展期到新 strike 或新到期日）。这类动作必须在富途客户端手动确认，并附带 需人工确认 标签。
  • 自动化执行受限说明：本报告仅作为人工决策依据，不默认自动下单。即便脚本层面支持，也必须在富途 App / OpenD 端二次确认后才视为有效。

仓位与策略前提

  • Covered Call 前提：必须持有对应正股 ≥100 股整数倍，否则无权卖出对应数量的认购期权。
  • Protective Put 前提：保护性认沽的成本会直接消耗现金，需确保账户可用现金 ≥ 期权权利金 + 手续费。
  • Short Put / Short Call 保证金：所有卖方策略都会冻结保证金，指派风险以 100 股为单位计算（例如 1 张 strike=$90 的 short put，被指派即需准备 $9,000 现金接货）。
  • 跳空风险：期权在隔夜 / 周末 / 财报后的跳空不可控，DTE < 7 的卖方仓位在事件发生前需要主动评估是否回补。
  • 数据缺口时的纪律：任何账户字段不可读时，默认进入「不主动操作」状态，仅做观察与监控，不下任何新订单。
